# 100 Days of Python — LeetCode

Solving one LeetCode problem in Python every day for 100 days.

Each day is a **single file at the root** of this repo (e.g. `Day1_Two_Sum.py`).
Every file contains my solution and, at the top, a short explanation **in my own
words** — covering every approach I tried and its time & space complexity.

Run any day directly:

```bash
python Day1_Two_Sum.py
```
